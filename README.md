## Key Features

- **Availability Status Badge:** Live pulse indicator showing current freelance/commission status.
- **Interactive Stacked Gallery:** Lightweight JS card-rotation engine with depth-based stacking and dynamic click logic (click front card to view in Lightbox, click rear cards to rotate).
- **Custom Lightbox Engine:** Advanced image viewer supporting mouse wheel zoom, trackpad gestures, multi-touch pinch zoom, and click-and-drag panning.
- **Dynamic Theme Switcher:** Dual-mode (Dark/Light) theme engine using CSS custom properties with persistent `localStorage` synchronization.
- **Interactive Modal System:** Universal overlay component for detailed tool breakdowns and personal focus deep-dives.
