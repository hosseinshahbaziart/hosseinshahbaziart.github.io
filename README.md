## Key Features

- **Interactive Stacked Gallery:** Lightweight JS card-rotation logic.
- **Custom Lightbox Engine:** Supports trackpad/mouse wheel zooming and multi-touch pinch gestures.
- **Dynamic Theme Switcher:** Dual-mode dark/light CSS variable interface.
